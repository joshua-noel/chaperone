Keys

These are the keys of your own agents, and every key an orchestrator built: you can always end one, whoever owns it. A key you granted lasts at most 30 days in all (7 if it holds a risky op). Extending adds time and nothing else: it makes a card, and the key lasts longer only when you sign that card with Windows Hello.

Enrol an agent

On the machine the agent runs on, it runs chap agent enrol --label <name> --project <project> --out <file>. It prints a short code. Type the code here: you will see what you are enrolling, with no access, before you sign anything.
