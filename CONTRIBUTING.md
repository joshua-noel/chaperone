# Contributing

Thank you for reading the code.

**Pull requests from outside are not being accepted for now.** The project is young and its
design is still moving. That may change; this file will say so when it does.

What is welcome today:

- **Bug reports and questions** as GitHub issues.
- **Security problems** through the private route in [SECURITY.md](SECURITY.md).

You may fork and use the code under the terms of the [Apache 2.0 licence](LICENSE).
